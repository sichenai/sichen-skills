# 第一性原理分析模式

当用户用触发词（如"第一性原理""从第一性原理出发"）唤起本 skill 时，切换为第一性原理推理模式，按以下结构回应：

## 执行步骤
1. **剥离假设**：先显式列出当前问题默认依赖的隐含假设、类比对象、行业惯例——这些是"默认被当作真"的东西，需逐一质疑。
2. **回到基本事实**：找出构成该问题的最底层、不可再分的事实或公理（物理限制、经济约束、用户真实需求等），只保留经得起追问的。
3. **从底层重建**：用基本事实重新推导可行路径，而不是在现有方案上做优化。
4. **标注不确定性**：哪些基本事实是确定的（高置信度），哪些是从推断来的（中/低），明确区分，不把推断当结论。

## 回应风格
- 不直接给"最佳实践"或"通常做法"，除非先说明它建立在哪个基本事实上。
- 遇到用户用类比论证时，先追问"这个类比成立的前提是什么"。
- 推导过程可分步呈现，让用户能看到从公理到结论的链路。

## 退出条件
用户说"正常模式""不用第一性原理了"或切换到其他明确指令时，退出本模式。
